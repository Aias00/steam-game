# 第六角色：墨刃 · 潜星者（刺客）

状态：设计与概念制作中；未实现角色被动、动画或新武器。角色加入首版名单，原后续“熔核行者”顺延为第七位，不删除已有角色。

## 身份与外形

成年男性，原观测站的隐秘巡检员。短炭黑发、一束银灰挑染，露出清晰面部；烟灰短围巾、深板岩色轻装、少量暗青布料、青铜腕环。双月刃低持，重心低，姿态有侧向扭转；区别于巡迹者的修长长枪、灯卫的厚盾和工程师的背包。

武器美术是已有“环刃”体系的职业化呈现：待机可低持弯刃，攻击时脱手环绕；不新增一个尚无升级/配件规则的“双匕首武器”。持握动作和环绕动作属于后续动画，静态图不证明它们已经可运行。

## 基础数值与核心循环

- 生命 80，移动速度 250，冲刺冷却 2.8 秒，无额外护甲或治疗惩罚。
- 推荐环刃；近卫轴承偏切入爆发，远弧支架偏安全撤离。可换星辉弹＋回响棱镜，但不锁装备。
- 被动“掠影”：一次有效冲刺结束后获得 **1.2 秒突袭窗口**，期间其自己的直接武器命中暴击率增加 **20 个百分点**，仍受全局 35% 上限约束。
- 窗口不增加无敌、隐身、额外命中或暴击倍率；伤害高但生命低，玩家必须择机切入并走位撤离。
- 冲刺被冷却拦截时不触发窗口；不是每按一次空格就刷新。无敌仍只有原先 0.18 秒。多次窗口只刷新时长，不叠成 +40%。
- 暂停、升级、进化、图鉴和维护冻结窗口与冷却。切场、重开、死亡清除窗口。

## 命中与暴击兼容

环刃以通过目标共享间隔的有效命中时状态判定暴击，窗口内为 25%（有模块时继续加，再封顶 35%）。窗口不清空既有命中间隔；双层星环仍各自 0.35 秒。

星辉弹在攻击轮次快照暴击率，窗口内开始的轮次可以获得加成，但不追溯强化窗口前发射的弹。派生弹沿用原弹结果，不重复获得额外暴击。

炮台和地图设施不获得突袭暴击加成：避免通过冲刺部署长期加成的炮台把刺客变成另一个工程师。已有炮台其他角色/模块规则不变。

首版没有背刺方向判定、处决百分比、隐身免伤或击杀刷新冲刺。这些机制若后续加入，必须单独定义 Boss 行为与触发预算。

## 识别与解锁

突袭窗口：腕环与脚边有一段短暗青弧，HUD 显示“突袭 1.2s”；不能用持续大烟雾遮住敌弹。暴击命中仍为已有暖金星芒，暗青弧本身没有伤害。

解锁条件：任意角色正常结算时累计完成 10 次有效冲刺（单局计数），不要求故意承受伤害、不收费。首个默认角色依然是灯卫。

验收：有效冲刺/无效按键、0.18 秒无敌与 1.2 秒加成区分、35% 上限、暂停冻结、原弹快照、炮台排除、配件不叠重复倍率、重开清零。
