## 1. 统一美术方向

沿用观测站遗迹世界，但把此前的几何占位人形升级为原创手绘卡通角色：有面部和材质区别、明确姿态、少而清晰的大色块。不要继续复制同一套蒙面斗篷换色。

视觉参考仅限“角色剪影清晰”“场景色彩有层次”“小尺寸战斗可读”这类原则，不复制已知 IP 的角色、服装、机器人头部或配色组合。

| 角色 | 剪影核心 | 主色 | 材质与辨识点 |
|---|---|---|---|
| 岩灯·灯卫 | 宽肩、矮壮、大灯盾 | 暖橙与苔绿 | 厚布披肩、磨损金属、方形盾面 |
| 逐隼·巡迹者 | 修长、短披风、长形武器 | 灰蓝 | 轻装、硬质镜片、向前的姿态 |
| 砾砂·织星匠 | 小个子、大背包、双浮灯 | 米白与铜色 | 工具、帆布、圆形护目镜 |
| **霁月·星图师** | **侧束发、短外套、偏置圆形星盘** | **雾紫、象牙白** | **布料与磨砂铜，露出面部，圆弧轨迹** |
| **R-07·螺灯** | **矮宽的椭圆机身、短腿、大机械手** | **奶油白、青铜、少量湖蓝** | **陶瓷面板、铆钉、非对称维修补片** |

角色专色只用于服饰和友方特效，不覆盖敌弹的危险色语义。缩成 64 像素、转成灰度后，五人仍应能通过轮廓识别。

## 2. 女性角色：霁月·星图师

### 身份与性格

成年女性，原观测站的星图测绘员。她重新进入遗迹，是为了找回散落的导航档案。性格沉静、敏锐，习惯先观察再行动；不是需要其他角色保护的剧情附属人物。

一句台词：“星图会变，回去的方向不会。”

### 外形

- 成年冒险者，立绘以已认可的 v001 修长绘画比例为准；战斗造型采用更紧凑的成年比例，姿态轻盈但不纤弱，不照搬早期 SVG 的身体结构。
- 深栗色侧束短马尾，额前留不对称刘海，铜制小星针作为近看识别点；脸部不被头盔或面罩遮住。
- 象牙白短外套、雾紫不对称肩披、深蓝实用长裤与短靴；腰间带卷起的星图袋。
- 左侧携带可展开的铜制星盘，构成身体之外的第二个轮廓；星盘是职业工具，不额外占武器槽。
- 服饰以侦察、测绘与移动的功能为依据，不使用与遗迹行动无关的礼服或高跟鞋。
- 主色参考：象牙白 `#E8DECA`、雾紫 `#9D94C4`、深蓝 `#303B56`、磨砂铜 `#B28A5B`。最终色值需要和场景一起检查。

立绘姿态：身体略侧向，抬起星盘观察前方，一脚轻微前移；表情自信而专注。避免和灯卫一样正面站直、双臂平放。

### 玩法定位

精准处理精英与 Boss，依靠观察和选择攻击时机，而非单纯增加移速。与巡迹者的“弹体穿透、清理成排敌人”区分。

| 项目 | 首轮初测值 |
|---|---|
| 基础生命 | 90 |
| 移速 | 240 |
| 冲刺冷却 | 3.0 秒 |
| 推荐武器 | 星辉弹 |
| 被动：星痕测绘 | 每 6 秒标记一个附近高威胁目标，持续 4 秒；自己对该目标的伤害 +25% |
| 代价 | 生命较低；同时只能标记一个目标，没有额外群体伤害或自动减伤 |
| 解锁 | 正常结算时，曾击败至少一只精英；解锁不额外收费 |

被动细则：

1. 目标必须在当前可见战斗区、距离不超过 600；Boss 优先，其次精英，其次当前生命最高的普通敌人；平局按稳定实体 ID。
2. 无合格目标时不消耗标记机会，下一次模拟步重新检查；成功标记后开始六秒间隔。
3. 单目标标记不叠层。标记目标死亡或持续时间结束后清除；不立即跳到另一名敌人，仍等待原六秒间隔。
4. 玩家自己的武器、进化弹体和武器炮台造成的伤害都可受益；地图炮塔不受益，不能让场景设施重复继承角色倍率。
5. 标记增伤作为一个独立角色倍率，与已有模块/核心倍率按 GAME_DESIGN 的伤害公式相乘，不再触发第二次伤害事件。
6. 暂停、升级、图鉴、进化界面冻结标记持续时间和冷却，不改变随机结果。

两条可测试路线：

- **精英点杀**：星辉弹＋环刃，先用星辉弹处理标记目标，环刃保护近身空间。
- **控场观察**：星辉弹＋引力新星，通过击退创造瞄准与拾取窗口，借标记提高 Boss 输出。

### 战斗反馈

标记使用金色的四段准星与小星图符号，不能只靠颜色；精英或 Boss 的标记放在轮廓外侧，避免盖住攻击预警。标记出现是一声轻短的玻璃/金属音，不频繁播放语音。

冲刺尾迹是两三笔短星线，快速消散；不留下完整的巨大星座图遮住弹幕。待机时星盘有轻微摆动，移动时短肩披和侧束发响应方向。

### 美术交付顺序

先交付一张完整三分之四视角立绘、正面/背面结构草图，以及一个 64 像素战斗缩略图。确认脸部、发型、服装轮廓和配色后再做移动、冲刺、受击与死亡动画。不可直接把大立绘缩小当作最终战斗精灵。

## 3. 机器人角色：R-07·螺灯

### 身份与性格

被遗弃的观测站维修机器人，原始职责是照亮通道并修补外墙。记忆有缺损，却还保留“把同伴带回营地”的旧指令。反应略慢、认真，有一点不自知的幽默。

一句台词：“照明正常。回家路线……重新计算。”

与织星匠区分：织星匠是提高设施和炮台效率的人类工程师；螺灯是依靠结构恢复与护盾续航的机器人，不再附加维修速度或炮台伤害加成。

### 外形

- 约 3–3.5 头身，矮而宽的椭圆陶瓷机身，两个有重量感的短足，不用人类套盔甲的身体结构。
- 单块横向表情窗，湖蓝色短线显示目光；不是大面积黑色头罩，也不做已知影视机器人的双筒眼造型。
- 身体前侧嵌入暖金照明灯，位置略偏一边；另一侧保留一块明显的补修铜板，形成不对称记忆点。
- 两只机械手大小不同：右侧是圆钝维修夹，左侧可承托装备。手臂粗短，关节清晰，头顶只有一根弯曲的小天线。
- 机身有少量擦痕和旧编号，不堆满细小电路纹理；远看先读出椭圆机身、短腿和灯。
- 主色参考：旧陶瓷白 `#DDD4B8`、青铜 `#8C7251`、湖蓝 `#78B9BB`、关节深灰 `#35423E`。

立绘姿态：身体微前倾，抬起一只维修夹，胸灯朝外；重心低、稳定，有温和的机械感。不能复用灯卫斗篷下摆再加方形头部。

### 玩法定位

稳健的续航与节奏管理：承受一轮攻击后拉开距离，等待护盾恢复，再回到火力区。与灯卫的“更高生命和范围伤害”形成差异。

| 项目 | 首轮初测值 |
|---|---|
| 基础生命 | 100 |
| 移速 | 210 |
| 冲刺冷却 | 3.2 秒 |
| 推荐武器 | 锚灯炮台 |
| 被动：旧式自检 | 连续 6 秒未受到有效伤害后，将自身护盾补满至 20 |
| 代价 | 移速较慢；治疗回复量为正常的 75% |
| 解锁 | 正常结算时，本局完成至少一处设施；同时解锁炮台与备用电池（若此前未解锁） |

护盾与伤害细则：

1. 开局护盾为零；六秒安全时间后补至 20。护盾不累加，没有超出 20 的溢出值，不因再次触发产生治疗。
2. 护盾先吸收伤害，超出部分扣生命。护盾受到有效命中也算受击，重置六秒安全计时并触发现有 0.65 秒受伤保护。
3. 冲刺无敌或受伤保护期间被忽略的命中不重置计时；有效命中为零不能反复刷出受击事件。
4. 六秒到期时护盾若已满，保持 20，不重新播放充能完成音效。护盾失去任意数值后需要重新满足连续六秒安全条件才补满。
5. 治疗包和模块的即时恢复均乘 75%；最大生命增加不打折，开局恢复满生命不打折。生命纤维仍加 10 最大生命，但当次恢复为 7.5；内部生命采用浮点数，HUD 显示规则与现有生命一致。
6. 护盾固定为角色被动，不占装备槽，不增加额外主动键；不附加过热、燃料、耐久或电池资源系统。
7. 暂停冻结护盾计时；重开一局清空护盾与计时，不能从结算带入下一局。

两条可测试路线：

- **阵地回环**：锚灯炮台＋环刃，在炮台周围绕行，环刃制造空隙以争取六秒自检时间。
- **安全距离**：星辉弹＋引力新星，减少近身接触，通过击退获得护盾恢复窗口。

### 战斗反馈

护盾用生命条下面的一条细湖蓝条表示，并标出“护盾 20”；不改变红色生命条含义，也不常驻第二个大型资源面板。归零时护盾条缩短淡出，恢复时亮起一次短铜环。

冲刺为短促的滑步加两三颗火星，保持和其他角色相同的无敌时长，不因视觉较重暗中变长。移动有小幅左右重心变化，避免强烈镜头抖动。

### 美术交付顺序

先交付三分之四视角立绘、正/侧/背结构草图、胸灯与补修板细节，以及 64 像素战斗缩略图。确认体块和关节活动范围后，再补行走、滑步、受击与关机动画。

## 4. 五人角色选择页

正式界面改为左侧三列两行的角色头像卡：五个有效位置，最后一格留空作版式呼吸，不伪装成一个付费或未开放角色。右侧展示所选角色的大立绘、基础属性、优势与代价，下方保留初始武器与出发。

角色头像卡负责“谁”，大立绘负责“长什么样”，属性区负责“怎么玩”，避免把五张全身长卡强挤进旧版三列空间。

## 5. 角色制作验收

- 女性与机器人各有独立身体结构、姿态和材质，不是旧角色换色。
- 五人转灰度、缩成 64 像素后仍能分辨；职业识别不依赖精细面部或文字。
- 霁月的标记不能覆盖敌方预警；标记死亡/过期/暂停和 Boss 优先级有确定规则。
- 螺灯护盾不无限叠加，不把冲刺免伤误计为有效受击；生命和护盾在 HUD 清楚区分。
- 两个新角色都能用至少两种已有武器搭配游玩，不依赖新增武器或额外按键。
- 数值只作为初测起点；需在零永久等级下验证输出、治疗、走位、精英和 Boss 表现，不能把此文档当作平衡已通过。
- v001 概念图和 v002 静态 PNG 已交付；静态资源不等于完整动画角色，美术落地仍需处理多朝向、行走、冲刺和受击。

## 8. v002 头像与静态战斗资产

头像由已认可原图裁切，输出 512/128/64px；战斗造型独立调用图片编辑接口，以对应 v001 图为参考。两张原始生成均为 1254×1254 RGBA，透明清理后输出 512/256/128/96/64px。参考图、提示词、原始输出、清理版、多尺寸文件与 SHA-256 均留存于 v002 清单。

处理脚本为 `scripts/prepare_character_assets.py`。网页角色选择页使用概念图和同源头像，战斗示例使用 96px 静态 PNG；已验证资源加载、角色切换和机器人独有护盾显示。没有以此宣称动画、实际角色伤害或 Godot 本体接入完成。

## 9. v003 原三角色调整与玩法核对

- 灯卫：暖橙厚披肩、短须与成熟面部、大灯盾；原 120 生命/215 移速、范围/环绕倍率保留，不把灯盾新增成未定义的第二套可再生护盾。
