# 战斗美术、动画与音效制作规格 v0.1

状态：制作设计与任务清单；本轮未将这些怪物/武器生成图或特效接入游戏。新角色的 v001/v002 是现有风格参考，不代表以下战斗资产已经完成。

规则来源：[COMBAT_DESIGN.md](COMBAT_DESIGN.md)，初始参数：[combat-v001.json](data/combat-v001.json)。已准备 [八份独立概念提示词](../art/prompts/combat/v001/README.md)；其中首批 W01/W02/E01/E02 已在 [v002](../art/prompts/combat/v002/README.md) 中补齐风格参考并生成，结果见 [概念图预览](../output/imagegen/combat-v002/index.html)。

## 1. 统一视觉约束

参考已认可的霁月与螺灯：温暖的绘画质感、奶油白与青铜、有体积的布料/机械、清晰大形。怪物延续“被星潮侵蚀的植物与观测站机械”，不能突然变成现代军事僵尸、写实血腥生物或纯几何方块。

读图优先级：敌方危险边界/弹体 > 玩家及其生命状态 > 怪物轮廓 > 友方攻击 > 经验 > 背景装饰。普通怪不要比玩家有更大、更亮的无关辉光。

- 友方核心与武器采用暖金、蓝白、薄紫；敌方攻击采用珊瑚红并附方向/斜纹/尖角。
- 阵营不只用颜色区分：友方炮台是稳定三足灯架，敌方炮台/术士是破损尖长镜架。
- 暴击金色属于命中反馈，不应把敌方地面危险也涂成金色。
- 画风一致不等于所有怪同色同形；四类普通怪必须在灰度与 48–64px 下辨认出职责。

## 3. 普通怪资产卡

| ID / 名称 | 身体/材质与剪影 | 移动特色 | 攻击预警与关键帧 | 受击与死亡 |
|---|---|---|---|---|
| E01 苔影追击者 | 圆钝低伏的孢壳、短足、壳缝细小裂光；苔皮与石质甲片 | 轻微挤压伸展，重心交替 | 接触型没有额外假施法动画；身体进近必须与碰撞一致 | 壳体短缩，死亡碎成少量孢屑，不能形成新的危险云 |
| E02 裂隙疾行者 | 细长低伏、两根后掠晶鳍、尾部向后；像星潮侵蚀的敏捷小兽 | 平时快跑，冲刺前明显刹停 | 压低身体并锁向 0.8 秒，脚下尖箭头；冲刺时拉长轮廓而非瞬移 | 冲刺被击杀时不完成剩余伤害；碎晶沿原方向散去 |
| E03 铜壳守卫 | 角形铜甲、宽足、竖向镜隙、单侧破甲；不可复用螺灯圆壳 | 慢而有重量，一步一重心 | 不画未实现的格挡姿态；其防御来自高生命，不误导成无敌护盾 | 压低肩甲/壳板小移位，死亡散成三四块大铜片 |
| E04 镜眼术士 | 悬浮破镜、三片尖长支架、中央单镜眼；不是人形法师换色 | 悬浮轻摆，距离过近时后移 | 镜片收束、镜眼沿锁定方向亮起 0.7 秒，再发射 | 镜架错位、死亡破成少量镜片；镜片是装饰，不再伤人 |

缩略尺寸初测：追击者 36–40px、疾行者 36–44px、守卫 48–56px、术士 40–48px；实际接入需与角色 64px、命中圆和摄像机比例一起检查，不机械按原图像素定碰撞。

## 4. 精英与 Boss

精英复用对应普通怪的身体资产和动作骨架，但增添一个大轮廓特征与一个招式，不仅描一圈红边。

- **三扇监守**：铜壳守卫上方增加三叶刻度冠，攻击时冠部依次定位三个扇区。危险是地面扇区，不是冠部本身。生命 1200 的初测不能用超大体型暗示成 Boss。
- **裂镜司仪**：镜眼术士外框破成三片分离镜翼；三镜连线预告三向慢弹，间隙可读。
- **失序守望者**：破损大型天文仪，中央核、内环、外环、支撑件分别可动。战斗显示约 110–140px，避免无故占据半屏。

Boss 的三个阶段用结构损坏/机械环重新排布表达，不仅换色。每个阶段切换保持目标位置与已存在弹体连贯；全屏闪白和瞬间消失不能替代阶段动画。

Boss 必做：出场、弹环蓄力/发射/恢复、锁向冲撞、扫描束、阶段切换、死亡。时间以 COMBAT_DESIGN 对应表为准，不以动画帧数反过来决定伤害生效时间。

## 5. 特效资源与时间轴

| FX ID | 资源/曲线 | 时序与行为 | 不得混淆的含义 |
|---|---|---|---|
| FX01 枪口/尾迹 | 小型手绘星核＋渐细尾迹纹理 | 0.04 秒枪口，约 0.08 秒尾迹 | 只表示飞行方向，不是额外命中范围 |
| FX02 刃弧 | 一段有绘画边缘的新月笔触 | 跟随真实刀刃角度，残留≤0.10 秒 | 轨迹内侧不持续造成伤害 |
| FX03 新星 | 低亮圆核、细刻度环、稀疏外散星点 | 0.12 秒达到结算时刻，之后约 0.25 秒淡出 | 填充不透明度≤0.12，不伪装持续 DOT |
| FX04 引力井 | 内收稀疏粒子＋收紧边界＋短爆发 | 0.45 秒牵引后一次爆发 | 没有额外隐藏吸附伤害 |
| FX05 友方护盾 | 湖蓝碎弧与小型明度脉冲 | 充能 0.15 秒、破盾 0.18 秒 | 不能用敌方红色表示自身恢复 |
| FX06 星痕 | 四段准星＋小星符 | 淡入/淡出各 0.12 秒，持续由逻辑驱动 | 标记不等于已经暴击 |
| FX07 敌方预警 | 实际走廊/扇区边界＋箭头/斜纹 | 按招式预警→生效→结束；取消动作同步取消 | 预警阶段无伤害，开始生效的边界要清楚 |
| FX08 暴击命中 | 一次短金色尖星＋比普通稍厚的接触点 | 约 0.10 秒；附短高频音色层 | 不生成额外爆炸伤害，不全屏震动 |

优先用少量手绘纹理＋曲线/粒子组合，不能要求模型一次生成一整张“帧帧一致”的多技能图来替代动画制作。纹理与碰撞数据分离。

## 6. 动画与贴图交付

### 6.1 从概念图到可用资产

1. 概念轮廓与材质确认。
2. 同画风的俯视静态首帧，透明边缘检查，放到真实背景做尺寸对照。
3. 同体块的移动、攻击、受击、死亡；关键预警按模拟事件驱动。
4. 再补其他朝向与进化，打包图集并验证纹理边缘。

不将一张大立绘缩小后称为完整动画；也不把含背景的 AI 图强行塞进战场。

### 6.2 文件规格

- 原图和每轮提示词留存，版本递增，不覆盖用户认可的参考。
- PNG 使用真实 alpha；不把棋盘格画入图片。若服务不支持透明，用单色底生成后另做抠图，并明确记录处理方法。
- 精灵母版建议 256px，角色/怪物按目标尺度输出 32/48/64/96px 变体；最终选择由同屏可读性决定。
- 武器图标单独输出；粒子/弹体使用小纹理，避免加载 2K 大图作为每个子弹实例。
- 朝向、脚底锚点、受击圆、攻击发射点与特效挂点在元数据中记录，不从全身 alpha 包围盒自动推断碰撞。
- 多帧切片保持相同画布与脚底基线，尾迹/武器摆动不能导致角色原地抖动。
- 灯卫、霁月和螺灯等不对称造型是否允许水平镜像，需要单独确认；不能无意把主手和识别补片来回交换。

### 6.3 图层与像素预算

低到高：背景→影子/地面装饰→友方低透明范围→单位与武器→友方弹体→敌方有效弹体→危险边界→伤害/状态标记→HUD。

普通粒子总预算初测 300、友方尾迹 60、存活飘字 40。高峰优先裁剪拾取小光点与友方尾迹，不能裁掉有效敌弹或危险预警。低特效模式保留单位与攻击边界。

## 7. 声音设计

| 类别 | 音色职责 | 限制 |
|---|---|---|
| 武器发射 | 星辉弹清脆短促、环刃轻风金属、新星低频蓄放、炮台机械节奏 | 同类射击至少间隔 0.08 秒，避免叠成噪音 |
| 普通命中 | 小、短、有接触感，按金属/孢壳轻微区分 | 不抢玩家受伤和敌方预警 |
| 暴击 | 在对应命中上增加一层短高频与尾音 | 全局至少间隔 0.12 秒，不用每次大爆炸 |
| 精英/Boss 预警 | 单独可辨、短而明确，与危险方向图形配合 | 最高优先级，不能被拾取声淹没 |
| 玩家受伤/破盾 | 两种不同音色；破盾偏玻璃/机械，生命受伤偏闷击 | 反馈来自有效结算，不按碰撞尝试反复触发 |
| 死亡与进化 | 事件性收束与释放，给予短暂情绪回报 | 不能持续遮盖下一轮危险提示 |

混音目标是有层次的战斗，而不是每一个实体都同时最大音量。所有设置提供独立静音/音量与减少动态效果选项，静音不影响任何战斗事件。

## 8. 制作批次与验收

**先做武器 W01/W02 和敌人 E01/E02**，验证精准点射、近身切割、基础追击与冲刺预警。然后完成 W03/W04 与 E03/E04，再做四进化、精英和 Boss。

八份基础概念提示词已逐个保存，首批四张已逐个输出、对照已认可风格并记录问题。其余四张、进化、精英与 Boss 仍待制作；不能用一张混合海报作为全部游戏资产。

每项验收：轮廓和职责一致、缩略与灰度可辨、透明边缘无底色、预警与命中位置一致、普通/暴击反馈可区分、减少特效不丢关键危险、峰值画面仍看得见玩家和敌弹。
