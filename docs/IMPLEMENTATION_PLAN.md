# 《星环余烬》首版实施与验收计划

状态：文档阶段，未开始执行本计划。本计划用于把设计拆成可以独立验证的增量，不承诺工期。

规则来源：[GAME_DESIGN.md](GAME_DESIGN.md) v0.5；视觉与交互来源：[../DESIGN.md](../DESIGN.md)。

专项依据：[COMBAT_DESIGN.md](COMBAT_DESIGN.md) 定义权威伤害、暴击、碰撞和敌人状态；[COMBAT_ASSET_BRIEF.md](COMBAT_ASSET_BRIEF.md) 定义美术、动画、技能特效与音效，不以临时圆点/方块当成最终资产。

## 1. 交付边界

首个完整单机版本：6 角色、4 武器及其进化、6 模块、1 地图、3 设施、4 普通敌人、2 类精英、1 个三阶段 Boss、局外解锁与有上限的核心成长。

仅在该版本有两套可玩的构筑、默认成长零可通关后，进入第七名角色（熔核行者）、霜火武器和其他场景开发。

本轮完成项是方案和文档；以下所有 M 阶段均是待执行任务。

## 2. 模块边界

| 现有位置 | 后续责任 | 约束 |
|---|---|---|
| `scripts/run.gd` | 单局状态、角色属性、装备、伤害、生成、材料、设施与胜负 | 不依赖 UI；固定种子可重现；保留可独立模拟的接口 |
| `scripts/game.gd` | 输入、相机、菜单、HUD、升级/进化/设施反馈、结算交接 | 显示实际状态，不维护第二套伤害与解锁规则 |
| `scripts/profile.gd` | 核心、解锁、记录、存档版本迁移与幂等结算 | 保留旧数据；临时写入后原子替换，错误可见 |
| `scripts/sound.gd` | 音量、事件音效和优先级 | 不改变模拟结果；高频音效限频 |
| `scripts/steam_bridge.gd` | Steam 状态与回调 | 单机功能不依赖在线；不纳入本轮网络功能扩展 |
| 后续配置资源 | 角色/武器/模块/敌人/波次参数 | 仅在实现时按现有模式建立必要数据表；不额外引入框架或依赖 |

## 3. 依赖顺序

`M0 基线 → M1 构筑与角色 → M2 精英与进化 → M3 地图设施 → M4 Boss 与关卡 → M5 营地与迁移 → M6 集成试玩`

各阶段结束时保留可启动版本；阶段中间未实现的功能不在正式 UI 宣称可用。M1–M4 的角色/装备测试通过隔离的临时进度开放内容，不提前修改真实玩家解锁。

## 4. 分阶段任务

### M0：建立正常数值基线

- 确认当前脚本、现有测试和正常存档位置；保存原型可运行检查结果。
- 用固定种子记录三个初始武器的击败数、升级时间、拾取比例和死因。
- 把首版参数整理为可验证的配置值，定义角色、装备、进化、设施和关卡状态 ID。
- 保留当前移动归一化、边界、受伤保护、暂停与结算回归测试。
- 增加独立暴击随机流、攻击来源 ID/所有者、事件快照和伤害日志；先验证统一公式再接视觉反馈。

验收：现有测试可运行；明确当前约三分钟模拟失败的原因假设；参数变更有正常数值前后对照，不仅有无敌模拟。

局部配件新增依据：[WEAPON_CUSTOMIZATION.md](WEAPON_CUSTOMIZATION.md)，八件、每武器一槽、三次维护机会。先做 P01/P03 验证快照与装配，再补全部配件；不增加第二槽或局外配件背包。

### M1：构筑、炮台与五角色

- 三武器槽、四模块槽，武器六级、模块三级。
- 基础四武器与炮台生命周期、替换上限、目标命中记录；星辉弹短点射、连续碰撞、环刃扫掠、范围技能一次结算。
- 玩家暴击与聚光镜改动；护盾/治疗/敌人/地图炮塔明确不共用暴击路径，碎弹继承而非重掷。
- 五角色选择、推荐武器、被动与代价；新增星图师标记、螺灯护盾及治疗折扣，细则见 [角色设计](CHARACTER_DESIGN.md)；任何角色可换用已解锁武器。
- 合格候选过滤、加权无放回抽样、前两级引导、免费重抽与不足三项时补给填位。
- 装备/进化图鉴显示当前等级与材料条件。
- 单武器配件槽、P01/P03 试装与快照、其余六件兼容；三次维护架、单武器候选不足、维修保底、替换确认与原子消费。

验收：无空卡、重复卡或满槽无效选项；重抽只消耗一次机会；炮台不无限累积；五角色同武器伤害与生命按规则计算；读界面不改变种子结果；标记按威胁确定选择且不叠层；护盾先吸收、有效受击重置六秒计时，暂停和冲刺免伤正确。

### M2：精英、材料与四武器进化

- 3:00/6:00 两类精英，唯一身份与固定碎片掉落。
- 材料本局保留、延迟进化、上限两次、原槽替换。
- 星雨分裂、双层星环、牵引爆发、移动灯塔；约束二次触发与单位上限；碎弹不能再按原弹最终伤害重复乘增伤/暴击。
- 四种普通怪预警、锁向、攻击和恢复状态，与两精英的唯一 ID/掉落一致。
- 进化选择独占 UI，完整暂停后一次性提交。

验收：先捡碎片后满足等级也可进化；连续按键不能扣两枚材料；分裂弹不再分裂；同环命中间隔生效；模块保留；Boss 不被无限牵引；两套首版构筑有正常数值对照。

### M3：苔光观测站与三设施

- 手工场地、可读的安全环路、设施方向与距离标记。
- 长按 E 0.6 秒选定即占名额，最多两处；未完成长按可取消，开始后不换选。
- 18 秒占点，织星匠 14.4 秒；离圈暂停、守卫仅一次、一次只累积一处。
- 炮塔局部火力、磁阵局部经验聚集、温室限量补给。
- 场景机关与武器召唤分别计数。

验收：名额计数与第三处锁定准确；暂停不产出治疗/经验；经验聚集前后总量相等；特殊掉落不被上限吞掉；三处都可通过正常移动到达；设施非通关硬门槛。

### M4：Boss、节奏与结算条件

- 1:30 设施开放、8:30 预告、9:00 Boss、10:00 停普通生成、11:00 硬截止。
- 三阶段 Boss；弹环缺口、预警冲撞和扫描束依次教学，保留输出窗口。
- Boss 出场避让玩家与设施圈；Boss 阶段降低普通生成量。
- 玩家死亡优先判负；11:00 及之前、玩家存活时击杀 Boss 立即胜利；无空等。
- 结算显示死因、进化、设施和伤害来源；有效伤害、过量伤害与护盾承伤分开统计。
- 技能 VFX 从伤害事件读取反馈，危险预警优先；普通/暴击数字分别聚合，低特效模式不裁掉有效敌弹。

验收：测试 8:59/9:00、9 分钟后提前击杀、10:00、10:59/11:00/11:01、同帧双方死亡、重复结算；慢速灯卫也有可用逃生路线。

### M5：局外成长、解锁与旧存档迁移

- 按 GAME_DESIGN 奖励公式计算，五级核心与固定价格。
- 存活两分钟解锁新星、三分钟解锁织星匠与炮台；击败精英解锁星图师、完成一处设施解锁螺灯及炮台；相关武器解锁时同时开放对应模块。
- `schema_version=2`；旧核心按实际购买公式退款并重新购买，保留余额与纪录。
- 迁移先备份；临时写入、正式替换、失败回滚；仅处理一次，重复启动不重复退款。
- 测试使用隔离路径；正常用户档不参与自动验证。

验收：新档、旧档零等级/高等级、损坏字段、迁移重试、新角色解锁的多条件合并、写入失败、连续重开都通过；购买不能负余额；结算不能重复发奖；无网络仍完成全部流程。

### M6：集成、可读性与正常试玩

- 用正常生命、正常伤害、零核心等级测试五角色；记录每局种子、进化时间、设施选择与死因。
- 六次升级前能理解装备关系，4–6 分钟有机会形成首个进化；记录未达成原因。
- 至少三名不同熟悉程度的试玩者各玩两局；样本小，仅作可用性排查，不宣称统计平衡。
- 有经验试玩者以零核心等级完成至少一局；每个角色至少两套搭配有可行证据，不能用无敌模拟替代。
- 正常图形负载检查粒子、敌弹、掉落、召唤、镜头边界和窗口缩放；保存峰值实体数和帧耗时。
- 验证暴击样本统计、表现开关不改模拟、浮点伤害/显示舍入和所有命中间隔；以 COMBAT_DESIGN 第 10 节的算例和边界为基准。
- 更新菜单/角色/战斗/升级/进化/设施/Boss/结算截图，测试状态标明来源。

验收：未完成任何项则记录缺口；未经过 Windows 真机测试不标记双平台已验证。目标是 Mac 与明确配置 Windows 机器的正常渲染 60 FPS；未达成则先限制效果与峰值数量。

## 5. 主要风险与处理

| 风险 | 观察证据 | 处理方向 |
|---|---|---|
| 十分钟拿不到关键升级 | 拾取率、首个进化时间偏低 | 优先调整经验曲线与拾取便利性，再改敌人生命 |
| 磁阵或治疗设施成必选 | 试玩选择过度集中、其他组合不可通关 | 调产出/覆盖区域/占点风险；不通过暗改掉落惩罚玩家 |
| 某个角色只剩一个正确武器 | 同角色换装明显失去可行性 | 增强通用能力或降低代价，不单纯把推荐武器继续加倍 |
| Boss 被控制锁死或秒杀 | 控制时间、实际击杀耗时异常 | 检查触发间隔、Boss 抗控制、伤害分类，再调生命 |
| 进化系统压倒其他选择 | 玩家只等固定公式、不再看卡 | 保留生存模块与设施取舍，控制每局两次进化上限 |
| 设施站圈变成强制站桩 | 被迫停下或无安全移动路径 | 保持足够占点半径、可离开保留进度、守卫只生成一次 |
| 迁移破坏进度 | 余额变化、重复退款、加载失败 | 保留版本和备份，验证幂等，失败保留旧档 |
