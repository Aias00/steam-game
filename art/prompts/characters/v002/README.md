## 保持身份

只使用用户认可的 v001 概念图作为参考，不使用旧 SVG。霁月保留面部、栗色侧束发、星针、象牙白外套、雾紫斗篷、深蓝裤装和铜制星盘；螺灯保留椭圆陶瓷壳、表情窗、天线、胸灯、补修板、短腿和不对称双臂。

头像由对应 v001 原图确定性裁切，不调用模型重画脸。战斗小人通过 imagegen 技能自带 CLI 的 `edit` 路径，附上对应 PNG 参考和完整提示词生成。请求模型 gpt-image-2、high、1024×1024，不降级模型、不修改技能脚本。

## 实际返回与透明处理

两张服务原始返回均为 **1254×1254 RGBA**，并非请求的 1024×1024。提示词要求纯绿背景以备抠图，但服务直接返回了真实 alpha，因此没有将绿色硬抠算法盲目套在图上。

原始返回以 `*-sprite-keyed.png` 保留（文件名来自生成前计划；实际为 RGBA），随后：

1. alpha≤8 的低透明噪点清零。
2. alpha≥240 的主体像素归为不透明。
3. 在原始分辨率收缩一像素遮罩，减少极细边缘杂点。
4. 按实际透明边界裁切，保持宽高比。
5. 以约 5.5% 留白、脚底对齐方式输出 512、256、128、96、64 像素方形 PNG。

处理脚本：[scripts/prepare_character_assets.py](../../../../scripts/prepare_character_assets.py)。没有用背景截图或旧 SVG 冒充新战斗造型。原始 API 结果、清理版与所有尺寸分别保留。

## 输出

每个角色都有：

- `*-avatar-crop.png`：源图裁切。
- `*-avatar-512.png`、`*-avatar-128.png`、`*-avatar-64.png`。
- `*-sprite-keyed.png`：原始生成文件。
- `*-sprite-clean.png`：原分辨率透明清理版。
- `*-sprite-512.png`、`*-sprite-256.png`、`*-sprite-128.png`、`*-sprite-96.png`、`*-sprite-64.png`。

输出均在 `output/imagegen/characters-v002/`。本轮没有覆盖已认可的 v001 概念图。
